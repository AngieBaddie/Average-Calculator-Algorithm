# Average-Calculator-Algorithm
Flowchart, pseudocode, and Python implementation of an average calculator algorithm.

## Overview
A simple algorithm that takes N numbers from the user,
sums them, and returns the average.

## Contents
- `flowchart/` — Visual flowchart of the algorithm
- `pseudocode/` — Plain English description of the logic
- `python/` — Python implementation with comments

## How to run
1. Make sure Python is installed
2. Run the script:
   python python/average_calculator.py
3. Follow the prompts
